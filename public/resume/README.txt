지원용 — 이력서·연락처 설정
==========================

[1] 영문 이력서 (원본 포트폴리오 /)
  - 파일: kiminhong-resume.pdf
  - 뷰어: /resume
  - 히어로·Contact "영문 이력서 확인하기"

[2] 국문 이력서 (원본 포트폴리오 /)
  - 파일: kiminhong-resume-ko.pdf
  - 뷰어: /resume/ko
  - 히어로·Contact "국문 이력서 확인하기"

[3] 네이버 지원용 (/naver)
  - 포트폴리오: /naver (사진·연락처 숨김)
  - 이력서: kiminhong-resume-naver.pdf → /resume/naver
  - 원본(/)에는 노출되지 않습니다.

[4] 연락처 (content.ts 상단 contact 객체)
  - email, phone 수정
  - /naver 페이지에서는 연락처·사진을 숨깁니다.

[5] 배포
  - PDF 넣은 뒤 git push → Vercel 자동 배포
